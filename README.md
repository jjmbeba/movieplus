## Installation

To get started with MoviePlus, follow these steps:

1. Clone the repository:
    ```sh
    git clone https://github.com/jjmbeba/MoviePlus.git
    ```
2. Navigate to the project directory:
    ```sh
    cd MoviePlus
    ```
3. Install dependencies using `pnpm`:
    ```sh
    pnpm install
    ```
